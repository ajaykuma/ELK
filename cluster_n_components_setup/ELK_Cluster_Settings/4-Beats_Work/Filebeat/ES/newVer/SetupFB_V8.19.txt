Filebeat now uses Data Streams instead of regular indices. 

So check if data view exists or create one
Kibana → Stack Management → Kibana → Data Views → Create data view

Name: filebeat-*
Index pattern: filebeat-*
Timestamp field: @timestamp
Click Save data view to Kibana

Then
Kibana → Discover → select filebeat-* data view from the dropdown

We can also filter by datasets
event.dataset : "elasticsearch.server"
event.dataset : "elasticsearch.audit"
event.dataset : "elasticsearch.gc"

Filter by log level to find warnings/errors:
--log.level : "WARN" or log.level : "ERROR"

Check audit logs:
--event.dataset : "elasticsearch.audit"

Check slowlog:
--event.dataset : "elasticsearch.slowlog"

Add useful columns in Discover by clicking fields on the left panel:

log.level ← already added
elasticsearch.cluster.name ← already added
event.dataset ← add this to see which log type each doc is from
log.logger ← shows which ES component logged it
