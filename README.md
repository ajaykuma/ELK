# ELK

Working with the ELK Stack: Elasticsearch, Logstash, Kibana & other plugins.
Will soon also include examples working with AWS OpenSearch & OpenSearch Dashboards.

> 🚧 This repository is currently being refined and improved. Stay tuned!

## Before You Start
- Please read through each example file completely before running it — setup steps or prerequisites are often noted inline.
- Scripts/configs are periodically updated and may need adjustment depending on the Elasticsearch/OpenSearch version you're using (check the version noted at the top of each file, if present).
- Any datasets referenced here can be found in my [Datasets_For_Work](https://github.com/ajaykuma/Datasets_For_Work) repository.

## What's Here
- **`Cluster_n_components_setup/`** — Setting up ELK clusters and individual components (Elasticsearch, Logstash, Kibana, plugins)
- **`AI-Integration/`** — AI/ML integration with Elasticsearch (e.g. embeddings, semantic/multimodal search)
- **`ScenarioTesting/`** — Testing specific real-world scenarios and use cases on the stack
- **`Working_exmpls/`** — Standalone working examples and reference scripts
